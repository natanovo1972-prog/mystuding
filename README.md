## Учебный проект "Виджет банковских операций"

## Описание
Проект разрабатывает новые функции для личного кабинета клиента банка. Виджет показывает последние успешные операции клиента банка.
На данном этапе в проекте реализованы следущие функции:
1. get_mask_card_number - функция принимает в качестве аргумента номер карты клиента и возвращает его маску - последние 4 цифры карты.
2. get_mask_account - функция принимает номер счета клиента и возвращает маску счета - последние 4 цифры.
3. mask_account_card - функция принимает тип карты и номер карты или номер счета и возвращает замаскированные данные.
4. get_date - функция принимает данные даты и времени и возвращает только дату.
5. filter_by_state - функция фильтрует операции по статусу выполнения.
6. sort_by_date - функция фильтрует операции по дате выполнения.
7. filter_by_currency - итератор для транзакций по заданному валютному значению.
8. transaction_description - генератор для последовательного описания транзакций.
9. card_number_generator - генератор вывода номер карт в указанном формате и диапазоне.
10. log - декоратор, логирующий начало и конец выполнения функции, а также результаты и ошибки выполнения

## Тестирование
Установлена библиотека pytest
В проект добавлены тесты для следующих функций:
## get_mask_card_number:
1. стандартный 16-значный номер;
2. номер меньше 16 цифр;
3. номер больше 16 цифр;
4. короткий номер;
5. пустая строка.
## get_mask_account:
1. стандартный 20-значный номер;
2. номер счета с пробелами;
3. номер счета больше 20 цифр;
4. номер счета меньше 20 цифр.
## mask_account_card:
1. нужная маскировка в зависимости от типа входных данных;
2. параметризация для тестирования ввода некорректных данных.
## get_date:
1. преобразование даты;
2. отсутсвие даты;
3. различные входные форматы дат.
## filter_by_state:
1. фильтрация списка словарей по заданному статусу;
2. отсутствие словарей с указанным статусом;
3. различные значения статуса.
## sort_by_date:
1. тестирование по датам в порядке убывания и возрастания;
2. проверка работы функции при одинаковых датах;
3. параметризация для тестирования некорректных форматов дат.
## filter_by_currency:
1. тестирование транзакций по определенному валютному значению;
2. проверка работы функции при отсутствии заданного валютного знаения;
3. проверка работы функции при пустом списке транзакций.
## transaction_descriptions:
1. тестирование генератора, возвращающего описание для каждой транзакции;
2. проверка работы генератора при пустом списке транзакций;
3. проверка работы генератора, если в списке одна транзакция.
## card_number_generator:
1. тестирование генератора на правильные номера карт в заданном диапазоне;
2. корректность форматирования номеров карт (номер карты должен содержать 16 цифр)
3. тестирование крайних значений диапазона номеров карт.
## test_log_success:
1. тестирование декоратора на успешное выполнение функции с выводом в консоль (фикстура capsys)
## test_log_error:
1. тестирование декоратора на обработку исключений с выводом в консоль (фикстура capsys)
## test_log_to_file:
1. тестирование декоратора на успешное выполнение функции с выводом в файл
## test_log_to_file_error:
1. тестирование декоратора на обработку исключений с выводом в файл
## test_log_correct_value:
1. тестирование корректного возвращения значения функции декоратором пользователю
## test_log_way_to_filename_error:
1. тестирование ошибочного пути к файлу
## test_log_args_empty:
1. тестирование функции с пустыми аргументами
## test_log_metadata:
1. тест, что метаданные не заменяются на wrapper
## test_log_arguments_correct:
1. тестБ что декоратор не искажает входящие аргументы


Запуск тестов:
bash
pytest tests/ -v
