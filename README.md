# Учебный проект по созданию ядра для интернет-магазина.
# Описание
Проект открывает работу над созданием ядра для интернет-магазина.
На данном этапе в проекте реализованы следующие функции:
1. # Создан класс Product (Продукт).
2. Класс Product дополнен методом new_product, который возвращает экземпляр класса Product на основе данных из входящего словаря.
3. Создан сеттер price.setter для проверки положительного значения цены продукта.
4. Добавлен магический метод __str__, который выводит наименование продукта, его цену и количество.
5. Добавлен магический метод __add__, который возвращает сумму произведений цены и количества продуктов.
6. # Создан класс Category (Категория).
7. В класс добавлены атрибуты количества продуктов и количества категорий.
8. Реализован метод add_product для добавления продуктов класса Product.
9. read_json - функция для чтения файла JSON.
10. created_object_from_json - функция создания объектов класса из JSON-файла.
11. Добавлен магический метод __str__, который рассчитывает общее количество товаров на складе для каждого продукта.
12. # Создан дочерний класс класса Product - Smartphone (Смартфоны).
13. В класс добавлены атрибуты: эффективность, модель, память, цвет.
14. Реализован метод __add__ , добавляющий продукты, относящиеся только к классу Smartphone.
15. # Создан дочерний класс класса Product - LawnGrass (Газонная трава)
16. В класс добавлены атрибуты: страна, период прорастания, цвет.
17. Реализован метод __add__ , добавляющий продукты, относящиеся только к классу LawnGrass.
18. # Создан абстрактный класс BaseProduct.
19. Класс BaseProduct - родительский класс для класса Product.
20. # Создан миксин-класс PrintMixin.
21. Класс PrintMixin добавлен в цепочку наследования класса Product, он выводит в консоль информацию, от какого класса и с какими параметрами был создан объект.

# Тестирование
Установлена библиотека pytest. Написаны следующие тесты:
# Для класса Product:
- тест на иницализацию атрибутов класса;
- тест на создание продуктов через класс-метод new_product;
- тест на изменение цены через сеттер;
- тест на сумму произведений стоимости товаров и их количество;
- тест на вывод ошибки суммы произведений товаров и их количества при некорректно введенном операнде.
# Для класса Category:
- тест на инициализацию атрибутов класса;
- тест на корректное суммирование данных двух атрибутов класса;
- тест на добавление нового продукта в категорию;
- тест на корректный формат вывода свойств продукта;
- тест на успешный вывод количества экземпляров каждого продукта. 
# Для чтения json-файла:
- тест на корректное чтение данных из json-файла;
- тест на отсутствие json-файла
# Для создания объектов класса из json-файла:
- тест на добавление в классы объектов из json-файла
# Для класса Smartphone:
- тест на инициализацию атрибутов класса;
- тест на успешное сложение продуктов класса Smartphone;
- тест на ошибку при сложении продуктов класса Smartphone с продуктами другого класса.
# Для класса LawnGrass:
- тест на инициализацию атрибутов класса;
- тест на успешное сложение продуктов класса LawnGrass;
- тест на ошибку при сложении продуктов класса LawnGrass с продуктами другого класса.
# Для класса PrintMixin:
- тест на корректный вывод строки о создании объекта класса.

Запуск тестов: bash pytest tests/ -v
